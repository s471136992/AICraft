# Contributing to AICraft

Thank you for your interest in contributing to AICraft.

We welcome developers who want to improve the project, report issues, suggest features, or submit code improvements.

## How to contribute

### 1. Report Issues

If you find a bug or have a suggestion, please create a GitHub Issue.

### 2. Suggest Features

You can share ideas about:

- New developer tools
- AI-assisted workflows
- Code improvement features

### 3. Submit Pull Requests

Steps:

1. Fork this repository
2. Create a new branch
3. Make your changes
4. Submit a Pull Request

## Development Guidelines

Please try to:

- Keep code simple and readable
- Add comments when necessary
- Update documentation when adding features

Thank you for helping improve AICraft.
